# API моделей PicPac

## AIAI.BY · FLUX.1 Kontext Pro

Серверный адаптер принимает `PICPAC_AIAI_API_KEY` из окружения и отправляет текстовые запросы иллюстраций на [`POST /v1/images/generations` с моделью `flux-1-kontext-pro`](https://aiai.by/models/flux-1-kontext-pro). Этот адаптер не отправляет фотографии. Для редактирования снимков используется отдельный шлюз PicPac с контрактом ниже; оба адаптера могут быть включены одновременно.

Публичный интерфейс размещён на Sites, API — на отдельном VPS за Caddy: `https://picpac.5-44-44-212.sslip.io/api/ai/`. Ключ находится только в окружении сервиса. Браузер получает гостевую подписанную сессию на один день; это не аккаунт и не удостоверение личности. Для ограничения расходов действует серверный общий лимит 12 заданий за 24 часа и 3 задания на гостевую сессию. Все задачи хранятся в одном файловом журнале; несколько реплик пока не поддерживаются.

Локальная подготовка фото для документов работает в браузере. При включённом шлюзе редактирования студийное превью отправляет один снимок только после подтверждения. Для подбора дизайна альбома можно отдельно включить [текстовую модель AIAI.BY](https://aiai.by/docs); ей передаётся только команда оформления.

## Схема

```text
Телефон → системная галерея → IndexedDB (неизменные оригиналы)
    ├─ Документы: MediaPipe на устройстве → исходник для контроля и заказа
    │       └─ по согласию: снимок + серверный промпт → отдельное студийное превью
    └─ Творческая студия: 1–3 снимка + запрос + согласие
            → PicPac API с авторизацией → сервер PicPac с моделью
            → закрытый результат → сравнение → новый вариант в проекте
```

Пользователь из Беларуси покупает услугу у PicPac. Закупку вычислений и договор с провайдером осуществляет PicPac. Оплата клиентом ещё не реализована: текущие заказы тестовые.

## Подключение для разработчика

1. Развернуть собственный inference gateway и закреплённую модель. Контракт ниже — **контракт PicPac**, а не готовый нативный endpoint Qwen, Yandex или Alibaba. Нужен обслуживающий модель адаптер.
2. Создать серверный `api/.env` по `.env.example`. Передавать значения через хранилище секретов хостинга; не помещать ключи в `dist`, репозиторий, URL или localStorage.
3. Для публичного MVP `POST /api/ai/session` выдаёт гостевую HS256-сессию. Перед платным запуском обязательны лимиты расходов. Для персонального аккаунта позже можно передать токен через `setAiSession({accessToken: async () => sessionToken})`.
4. Запустить локальный сервер Node 20.6+: `node --env-file=api/.env server.mjs`. Без настройки возвращается `connected:false`. Сервер слушает только localhost.
5. Публичный Node API слушает только `127.0.0.1:8081`; Caddy проксирует `/api/ai/*` на отдельном HTTPS-домене. `dist/ai-config.json` задаёт этот адрес. Если API пакуется отдельно от сайта, включите серверные модули из `api/` и общие контракты `dist/album-design.js`, `dist/document-studio-profile.js`.
6. До включения реальных платежей подключить серверный баланс/резервирование стоимости, возвраты, журнал расхода, базу/очередь заданий и объектное хранилище. Текущий файловый журнал предназначен для одного процесса и интеграционных испытаний, не для нескольких реплик.

Переменные для AIAI.BY: `PICPAC_AI_ENABLED=true`, `PICPAC_AUTH_SECRET` (не менее 32 случайных символов), `PICPAC_AIAI_API_KEY`, `PICPAC_PUBLIC_ORIGIN`, `PICPAC_PORT`, `PICPAC_DAILY_JOB_LIMIT`, `PICPAC_GLOBAL_DAILY_JOB_LIMIT`. Альтернативный inference gateway использует `PICPAC_MODEL_GATEWAY_URL`, `PICPAC_MODEL_GATEWAY_KEY`, `PICPAC_EDIT_MODEL`, `PICPAC_GENERATE_MODEL`.

Для студийного превью нужны `PICPAC_DOCUMENT_STUDIO_ENABLED=true` и настроенный шлюз `PICPAC_MODEL_GATEWAY_URL` / `PICPAC_MODEL_GATEWAY_KEY` с операцией редактирования. Модель берётся из `PICPAC_EDIT_MODEL` (по умолчанию `Qwen-Image-Edit-2511`). Для команд альбома опционально задайте `PICPAC_ASSISTANT_MODEL` и `PICPAC_AIAI_API_KEY`. Без этих настроек локальная фотостудия, валидатор и прямые команды альбома продолжают работать.

Для AIAI.BY задайте `PICPAC_AIAI_DOCUMENT_EDIT_MODEL=seedream-4-edit` и включите `PICPAC_DOCUMENT_STUDIO_ENABLED`. Адаптер использует существующий `PICPAC_AIAI_API_KEY` и отправляет один файл и серверный промпт в OpenAI-совместимый `POST /v1/images/edits`. Этот маршрут вернул изображение при живой проверке Seedream 4 Edit. Перед переключением на другую модель проверьте редактирование на тестовом снимке.

Вместо собственного шлюза можно включить прямой адаптер [Qwen Image Edit в Alibaba Cloud Model Studio](https://help.aliyun.com/en/model-studio/qwen-image-edit-api): задайте секрет `PICPAC_DASHSCOPE_API_KEY` региона Singapore и при наличии `PICPAC_DASHSCOPE_WORKSPACE_ID`. Адаптер работает только для `document.studio.preview` и отправляет модели `qwen-image-2.0-pro` один JPEG и серверный промпт. После настройки перезапустите API и убедитесь, что `GET /api/ai/capabilities` содержит эту операцию.

JWT: `alg=HS256`, `iss=picpac`, `aud=picpac-ai`, `sub` — случайный идентификатор гостевой сессии, `exp` не далее 24 часов от проверки, необязательный `nbf`.

## API приложения

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/api/ai/capabilities` | Доступные операции; без авторизации, без секретов. |
| POST | `/api/ai/session` | Выдать гостевую подписанную сессию. |
| POST | `/api/ai/jobs` | Создать задание. Bearer-сессия и `Idempotency-Key` 16–128 символов обязательны. |
| POST | `/api/ai/assistant` | Предложить правки дизайна из `{ "instruction": "…" }`, до 500 символов; нужна Bearer-сессия. |
| GET | `/api/ai/jobs/:id` | Статус только собственного задания. |
| GET | `/api/ai/jobs/:id/result` | JPEG только владельцу; `Cache-Control: no-store`. |

Тело создания:

```json
{
  "operation": "photo.edit",
  "prompt": "Спокойный сад на фоне, сохранить лицо и естественную текстуру кожи",
  "references": [{"mimeType": "image/jpeg", "data": "BASE64_BYTES"}],
  "consent": true
}
```

`photo.edit` требует 1–3 JPEG/PNG/WebP до 5 МБ каждый. `art.generate` требует пустой список исходников. Для этих двух операций поле `consent` обязательно. `document.studio.preview` принимает `documentId` (`by`, `schengen` или `residence`) и ровно один исходник. После успешной проверки снимка с камеры запрос запускается автоматически, а для загруженного фото — по кнопке студийной обработки. Сервер подставляет фиксированный промпт, а браузер кодирует JPEG без EXIF с длинной стороной до 2000 px. Общий лимит JSON — 22 МБ; сервер проверяет сигнатуру файла. Для полноценного production ingress добавить декодирование, лимит пикселей и повторное безопасное кодирование на сервере.

Ответ задания: `id`, `status` (`queued/running/succeeded/failed`), даты, `operation`, безопасная ошибка, результат при готовности. Повтор с тем же ключом и телом возвращает то же задание; другое тело с тем же ключом → 409. Новый осознанный запрос требует нового ключа. Автоматического повтора платного вызова нет.

Ограничения: два активных задания на сессию, два на процесс в текущем развертывании, три в сутки на сессию и двенадцать в сутки на весь сервер. Лимиты действуют внутри одного процесса. Источники и запрос не записываются на диск. Изображение хранится один час с момента создания задания, уборка выполняется при запуске, запросе истёкшего результата и раз в минуту. Метаданные журнала сохраняются для идемпотентности. После перезапуска незавершённые задания отмечаются как failed и не запускаются повторно.

## Аккаунты

Сервер PicPac на Node.js 24 хранит аккаунты и сессии в `accounts.sqlite` рядом с журналом ИИ-задач. Новая учётная запись получает Standart. Назначение тарифа выполняется из каталога приложения от имени пользователя службы. Доступные значения — `standart`, `pro`, `super`, `vip`.

```sh
node api/accounts.mjs set-plan user@example.com pro
```

Если служба использует `PICPAC_JOB_DIRECTORY`, передайте тот же каталог при запуске команды. Активный тариф обновляется в браузере после перезагрузки страницы.

## Контракт PicPac inference gateway

Backend отправляет `POST /v1/images/edit` или `/v1/images/generate` на доверенный адрес из окружения, `Authorization: Bearer MODEL_GATEWAY_KEY`:

```json
{
  "model": "Qwen-Image-Edit-2511",
  "prompt": "...",
  "images": [{"mime_type":"image/jpeg", "base64":"..."}],
  "n": 1,
  "output_format": "jpeg",
  "preserve_identity": true
}
```

Gateway возвращает `{"model":"...", "data":[{"b64_json":"JPEG_BASE64"}]}`. `preserve_identity` — указание адаптеру, не гарантия сохранения внешности. Результат до 15 МБ JPEG, ответ до 22 МБ; timeout 120 секунд. URL результатов и HTTP-редиректы отклоняются; произвольные адреса из пользовательского тела не запрашиваются.

Фронтенд опрашивает статус задания. Студийное превью хранится отдельно от оригинала; изменение исходника, документа или кадрирования прекращает ожидание результата, но не отменяет уже начатые вычисления. Автоматического восстановления опроса после перезагрузки пока нет. До коммерческого запуска нужен экран незавершённых задач и отображение стоимости.

## Критерии качества перед включением

Сравнить модели на согласованном наборе снимков PicPac: дети/взрослые, очки, тёмные волосы, сложный фон, низкий свет. Проверять лицо, естественность кожи, фон и края. Для документных заказов и экспорта всегда используется исходный снимок. ИИ-превью не подтверждает пригодность фото для подачи.

`node --test tests/*.test.mjs` проверяет доменные ограничения, подпись сессии, изоляцию владельцев, идемпотентность и ограничения адаптера. Реальные платные модели тестами не вызываются.
