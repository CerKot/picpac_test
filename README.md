# 📸 PicPac

### Твоя фотография. Твой стиль. Твои возможности.

**PicPac** — современное приложение для работы с фотографиями, объединяющее удобное редактирование, подготовку фотографий на документы и возможности искусственного интеллекта.

Создавай красивые изображения, экспериментируй со стилями, используй готовые шаблоны и превращай обычные фотографии в нечто особенное.

## 🚀 Установка и запуск

### 1. Клонирование проекта

```bash
git clone YOUR_REPOSITORY_URL
cd PicPac
```

### 2. Установка зависимостей

Установите Node.js версии 20.6 или новее.

Установите зависимости проекта согласно `package.json`.

### 3. Настройка окружения

Перейдите в папку `api` и создайте файл `.env` на основе `.env.example`.

Пример конфигурации:

```env
PICPAC_AI_ENABLED=true

PICPAC_AUTH_SECRET=YOUR_SECRET

PICPAC_MODEL_GATEWAY_URL=YOUR_API_URL
PICPAC_MODEL_GATEWAY_KEY=YOUR_API_KEY

PICPAC_MODEL_GATEWAY_PROTOCOL=openai-images
PICPAC_EDIT_MODEL=flux-1-kontext-pro

PICPAC_PUBLIC_ORIGIN=http://127.0.0.1:4173
```

**Важно:** API-ключи должны храниться только на сервере. Не добавляйте секреты в клиентский код и публичный репозиторий.

Для полноценной AI-генерации необходимы настроенный API-провайдер и авторизация PicPac.

### 4. Запуск

```bash
node --env-file=api/.env server.mjs
```

## 🔐 Безопасность

Безопасность пользовательских данных — важная часть PicPac.

- API-ключи не должны передаваться в клиентское приложение.
- Секретные настройки хранятся в переменных окружения.
- AI-запросы проходят через серверный шлюз.
- Оригинальные фотографии сохраняются отдельно от результатов обработки.
